# IVM-XYZ

Convert between Cartesian and Quadray coordinates in Python. IVM-XYZ also
provides vector operations, tetrahedron and triangle measurements, regular
polyhedra, and optional Matplotlib visualizations.

- [Install and use the package](docs/package-guide.md#installation).
- [Browse the documentation](docs/DOCUMENTATION_INDEX.md).
- [Build the manuscript](docs/manuscript/README.md) and reproduce the coordinate checks.

Requires Python 3.11 or newer. [Release history](docs/releases/CHANGELOG.md) · [MIT License](LICENSE)
