# Abstract

A Quadray coordinate tuple represents a point through four tetrahedral
directions. This paper checks how IVM-XYZ converts between Quadray and
Cartesian coordinates. An octant fixture exercises the signed-coordinate
cases and checks invariance to a common coefficient shift. A regular
tetrahedron supplies an independent edge and volume check. The results
record both the library's normalized volume convention and the determinant
volume in ordinary cubic coordinate units.
