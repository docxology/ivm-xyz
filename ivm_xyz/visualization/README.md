# `ivm_xyz.visualization`

3D polyhedron plotting and animation via **matplotlib** (required). GIF animation also uses **imageio** when saving animations.

Install: `pip install -e ".[visualization]"` or `uv sync --all-extras` from the repo root.

See [../../docs/MODULES.md](../../docs/MODULES.md) and [AGENTS.md](AGENTS.md).
