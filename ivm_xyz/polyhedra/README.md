# `ivm_xyz.polyhedra`

Base `Polyhedron` / `Edge` types, Platonic solids, and edge-counting helpers used in synergetics-style layouts.

See [../../docs/MODULES.md](../../docs/MODULES.md) and [AGENTS.md](AGENTS.md).

**Note:** `Tetrahedron` here is exposed as `PolyTetrahedron` in [`__init__.py`](__init__.py) to avoid clashing with `ivm_xyz.core.Tetrahedron` (edge-length tetrahedron).
